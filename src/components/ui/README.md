# Vangrex animated UI components

These 61 TSX files are animated replacement copies of the matching files from `src/components/ui`. Existing color classes and component APIs are preserved. Interaction transitions use longer eased motion, popovers and dialogs expand from a smaller scale, sheets travel farther on entry/exit, and controls have tactile hover, focus, and press states. Reduced-motion variants are included where continuous animation is used.

Copy these files into `src/components/ui` to use them. The source folder was left unchanged because this session only received read permission for it. `direction.tsx` is a provider with no rendered UI, so it is included unchanged.
